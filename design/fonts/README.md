# Open fonts (manifest only)

Templates use OFL-1.1 families from pinned Ubuntu packages (`fonts.json`: file, family, style, sha256, package version, license). No font binaries are stored in the repo (PRE_DELIVERY_CHECKLIST). Install with `apt install fonts-noto-core fonts-crosextra-carlito fonts-liberation`; on Windows install the same Noto Sans / Noto Sans Display / Noto Serif / Noto Sans Arabic / Noto Naskh Arabic, Carlito and Liberation Sans files. `MATN_FONT_DIR` is no longer used. See ADR-0019.
