# Evaluation set

Five public PDFs (3 dev, 2 test) with a reference ("silver gold") of key points and key numbers. Every item is tied to
a 0-based page index, the printed page label, and an exact quote, and is verified by code.

| Path | In git | What |
|---|---|---|
| `incoming/*.pdf` | no | the PDFs (sha256 pinned in `registry.json`) |
| `incoming/SOURCES.md` | yes | public source of every PDF |
| `splits.json` | yes | dev/test assignment and rationale |
| `registry.json` | yes | sha256, pages, labels, text-layer check, page-text hashes, source, split |
| `pages/<doc_id>/pNNNN.txt` | no | page text from PyMuPDF `page.get_text("text")`, regenerated by `register.py` |
| `gold/<split>/<doc_id>.json` | yes | the reference, schema `gold/schema.json` |
| `gold/MANIFEST.json` | yes | sha256 of every gold file; after it exists the test split is sealed |

```bash
python eval/register.py                      # registry + page text (gates: 5 PDFs, sources, text layer, 3/2 split)
python eval/verify_gold.py --split dev       # 0 failures required
python eval/freeze.py --check                # gold unchanged since freeze
python -m pytest eval/tests -q               # normalization + verification tests
```

The test split (`gold/test/`) is read only at milestones: start the session with `EVAL_MILESTONE=1`
(hook R4 and `verify_gold.py` both enforce this).
