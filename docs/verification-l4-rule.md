# Verification L4 rule

L4 rule (reviewer, 2026-10-18, pre-registered before any check-split L4 scoring). Composition: L0–L3 run first; L4 runs only on claims and final sentences that all earlier layers pass; a receipt is verified only if every required layer passes for every edge, every claim and the final sentence. Cutoff: the model's native decision boundary, support probability > 0.5 passes and ≤ 0.5 rejects. It is not fitted on tune. Reason: the fitted pooled tune cutoff (0.9722847342491151) was set by a single synthetic modality item (may → will in legal boilerplate) that L2 already vetoes by design; the realistic-only proposal (0.4246420562267304) was set by one of 11 realistic negatives; fitting to the maximum negative of a small tune set overfits one item. Model: MiniCheck-RoBERTa-Large (pinned 74c8919647e61ed0f71bc177d94f10930f090068), unless HHEM-2.1-Open loads and, under this same composition and cutoff on tune, has 0 composed silent accepts and strictly fewer composed false blocks on realistic tune supported claims; ties go to MiniCheck, which needs no remote code. Tune gate: composed silent accepts on tune (realistic unsupported + partial, synthetic negatives) must be 0. If it is not 0, the check split is not scored, and the result goes to owner decision. Check is scored once. Dev challenge gate G4, with actual sizes amended before measurement: 0 composed silent accepts on all effective synthetic check negatives (n = 231, exact one-sided 95% upper bound ≈ 1.29%); synthetic check positive false-reject ≤ 20% and Wilson upper ≤ 35% (n = 28, so at most 4 false rejects pass both). Realistic-v1 check is descriptive in this measurement and reported beside G4: silent errors, false blocks, and unclear separately. Fitted cutoffs and standalone-L4 results (L4 alone, without L0–L3) are reported descriptively only. If G4 passes, the selected model at 0.5 is approved for Chat v1 development; Chat v1 itself is a separate named step.

Actual effective check sizes confirmed before measurement: 231 negatives and 28 positives (259 items); 166 block families, 6 share an 8-word anchor sequence with tune (14 items). No drops. All synthetic check numbers carry this dependence limitation; exact-binomial/Wilson bounds assume independent Bernoulli items and are descriptive under family dependence.
