# Public portfolio copy

This repository preserves the engineering history and tests of Matn under the owner's author and committer identity. Internal review reports and coordination records have been omitted. Commit dates are retained; history IDs change because the public copy has different authorship metadata and omits private evaluation material.

The sealed evaluation gold is excluded from all public history. Its registry split entries remain to preserve the evaluation boundary. PDFs, model weights, wheels, package archives, environments and generated run outputs are excluded.

Evaluation labels and questions remain model-produced where that was their origin. Neutral provenance distinguishes model family A from model family B, preserves the six owner-reviewed items and fourteen delegated model reviews, and states that delegated reviews were not independent of drafting and are not human gold. Cross-family screening is model screening, not human verification. Pending human checks remain pending.

Source-paper model names in quoted evidence remain verbatim. Embedded image bytes remain unchanged. Public-copy provenance fields, artifact names and commit references were neutralized or remapped, and their dependent metadata hashes were updated. Question wording, evaluation splits, exact target text, offsets, deterministic IDs, numeric values, OCR rules and thresholds were not retuned. These metadata changes are not a new evaluation run or a new human validation.

The public copy keeps forbidden-file and test hooks. Commit-trailer enforcement and its dependent tests are omitted. Tests that verify demo routing, caching and rendering use deterministic synthetic image/PDF fixtures in temporary directories because the local source PDF is not distributed; those fixtures are not source-paper evidence.

Local PDFs, cached evaluation outputs, model files, original diagnostic reports and delivery bundles are not provided by this repository. Reproduction commands that depend on those artifacts require separately authorized local inputs. Historic measurements remain conditional on their recorded reference and scope; public-copy test results do not replace those measurements.

OCR integration tests require matching local OCR weights and a local OCR environment; the real-scan integration also requires its verified source PDF. They skip explicitly when those inputs are absent, preserving their assertions for installations with the inputs present. These skips do not establish OCR accuracy or integration success.
